# Settings API

**Users API:** Use this API to fetch information about users in the account, along with updating their working hours, timezone, additional phone number, and job title properties.

**Business Units API:** The following endpoint provides information about [business units](https://knowledge.hubspot.com/account-settings/manage-brands-with-business-unit) tied to a user.
